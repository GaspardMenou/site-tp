# Photos de la galerie

Dépose ici les photos de soirées (`.jpg`, `.png`, `.webp`…) :
elles apparaissent **automatiquement** dans la galerie du site, triées par nom
de fichier, optimisées et incluses au build. Rien d'autre à faire.

## Conventions de nom (optionnelles)

- **Ordre** — préfixe le nom d'un numéro : `01 - warehouse.jpg`, `02_crowd.jpg`.
  Le numéro sert au tri, il ne s'affiche pas.
- **Format** — un nom contenant `wide` → grand format (paysage),
  `tall` → portrait. Sinon format standard.
  Ex : `02 - crowd wide.jpg`, `05 - 4am tall.jpg`.

Tant que ce dossier est vide, le site affiche des images de remplacement.
